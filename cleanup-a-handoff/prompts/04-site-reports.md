## Per-function contract

### `getSiteDays(input)`

Default `days = 14`. Window ends at today in project TZ.

Read `site_frames` for `project_id = input.projectId` within window, ordered by
`captured_at asc`. Cap 500 frames.

Group by calendar day. For each day return one `StoryboardDay`:
- `date` = `YYYY-MM-DD`
- `frames` = array of `{id, capturedAt, capturedBy, photoUrl, caption, voiceClipUrl, incidentCount}`
  - `voiceClipUrl` from joined `voice_notes` table (one optional per frame)
  - `incidentCount` from joined `incidents` (where `linked_frame_id = frame.id`)
- `summary` = either the stored daily summary row (`site_day_summaries`) or `null`
- `weatherTag` from `site_frames.weather_tag` (mode of frames within the day)

Order days desc (newest first — that's the storyboard scroll direction).

### `getIncident(incidentId)`

Single SELECT on `incidents` joined with `site_frames` (for the source frame),
`projects` (for label), `users` (for `reported_by` and `assigned_to`).

Return `IncidentDetailProps`:
- `incident.severity` = pass `severity.ts` `classify({ description, photos })` for display tone (don't re-store; the row's `severity` column is the source of truth, severity.ts is for the agent's classification on submit)
- `relatedFrames` = up to 5 other frames from the same villa within ±3 days

Return `null` if not found or scope mismatch.

### `getWeeklyReport(projectId, isoWeek)`

`isoWeek` is `YYYY-Www` (e.g. `2026-W22`). Look up `weekly_reports` for
`(project_id, iso_week)`.

If `status = 'draft'` and the row was generated by the agent: also include the
composer's source frames so the supervisor can review what went in. Pull
`source_frame_ids` json array, JOIN `site_frames`.

If `status = 'published'`: return the canonical render data only (no source
frames needed).

Return `null` if not found.

### `submitSiteFrame(input)`

1. Validate `input` shape (use the existing zod schema from `capture-flow.tsx`'s draft type).
2. Insert `site_frames` row with `project_id`, `captured_by = authorUserId`, `captured_at = now()`, `photo_url`, `caption`, `weather_tag`.
3. If `input.voiceClipUrl` is set, insert a `voice_notes` row linked to the frame.
4. If `input.incident` is set, insert an `incidents` row with `linked_frame_id`, severity from `severity.classify()`, `status = 'open'`, `reported_by = authorUserId`.
5. Wrap in transaction. Return `{ frameId }`.
