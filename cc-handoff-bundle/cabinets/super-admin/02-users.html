The user table cuts across every organisation on the platform. The high-stakes flow this cabinet owns is Reset MFA — irreversible, audit-logged, 2FA-gated on the operator.

Reset mode

Send re-enrolment link
User receives email + SMS. Current MFA stays active until user completes re-enrolment. Safest default — no temporary unprotected window.
Force-disable MFA
Immediate. User can sign in with password alone. Use only when user has lost MFA and re-enrolment link is undeliverable. Recommend pairing with a password reset.
Temporarily disable for 24h
MFA off for 24h, then re-enrolment required. Good for support-window scenarios.
