04—Spec

Schema · cost model · throttling

Agents share one runtime (src/lib/agents/run.ts). Every call writes a row to agent_runs with token counts + cost (computed from model_registry at call time). Throttling is enforced at the runtime entry point, not inside the agents — that way one bug in one agent can't cost-explode the platform.

Tables · new for 2.5

agent_registry
id · key · name · description · owner · stage · trigger (cron/on-event/on-demand) · prompt_version · created_by · archived_at
agent_runs
id · agent_id · org_id (nullable) · model · prompt_tokens · completion_tokens · cost_usd · duration_ms · outcome · run_args_jsonb · linked_audit_id — joined to cabinet 07
agent_caps
agent_id · scope (platform/tier/org) · scope_id · monthly_usd · daily_usd · runs_per_min · effective_from · version
model_registry
model · provider · prompt_usd_per_1k · completion_usd_per_1k · max_tokens · default_for[] — registry of available models and their prices

Cost computation

per-run
(prompt_tok / 1000) × prompt_price + (completion_tok / 1000) × completion_price. Computed at write time from model_registry snapshot.
per-org
Sum of cost_usd over (agent_id, org_id) + window. Indexed for fast cap-check at runtime.
platform
Sum across all orgs per agent. Daily soft/hard caps watched by cost-warden agent (cabinet 08).

Throttle enforcement

order
1. kill → noop. 2. org-cap → skip with logged reason. 3. tier-cap → skip. 4. platform-cap → queue with backoff. 5. allow.
where
Inside src/lib/agents/run.ts before model call. Never inside individual agents.
signals
Throttled runs still write a row to agent_runs with outcome = throttled and cost_usd = 0. Showed up in cabinet 06 and 08 dashboards.

Customer visibility

org admin
Sees own org's spend + cap status in the org-settings page of Mgmt / Dev OS. Cannot see other orgs' data.
opt-out
Per-agent opt-out flag honoured (e.g. Tan Family disabled draft-replier for privacy). Hides AI surfaces in their cabinets.
cap exceeded
Customer sees a soft inline banner "AI features paused for this month — extend cap"; never silent failure.
audit
Every throttle, kill, override writes to audit_log (cabinet 07).
