Phase 2.5 · cabinet 06 of 09

Support inbox · tickets, AI drafts, escalation.

Every ticket from every org in one queue. Sales handles billing & how-to questions; the tech lead picks up the bugs and escalations. AI drafts a reply on every incoming message — it doesn't send anything; it just lines up the right answer so an operator can edit-and-ship in one click. SLAs are tier-aware: Atelier-tier orgs jump the queue.

04—Spec

Schema · agents · routing

Tickets come in via three channels — in-app composer, email-to-ticket gateway, and the AI agent surface (e.g. when an agent run fails and writes a customer-facing summary). All three normalise to the same support_tickets + support_messages tables. AI replies are drafts, never autosends (except where explicitly enabled per category).

Tables · new for 2.5

support_tickets
id · org_id · subject · category · priority · status · assignee_id · sla_first_reply_at · sla_resolution_at · escalated_at · resolved_at
support_messages
ticket_id · author_type (cust/staff/agent) · author_id · body · attachments · is_internal_note · created_at
support_drafts
ticket_id · agent · body · confidence · sources_jsonb · created_at · accepted (bool) · edited_distance
support_policy
version · categories_jsonb · tier_overrides_jsonb · created_by · effective_from

Agents

triage-router
Runs on every incoming message. Classifies category + priority. Writes internal note + dispatches to the right team queue.
draft-replier
Runs on every customer message in an open ticket. Drafts a reply, retrieves 3-5 context sources, writes to support_drafts with a confidence score.
sla-warden
cron every 5m. Pages the right team when first-reply or resolution targets approach. Atelier-tier breaches slack tech lead directly.
weekly-csat-rollup
Mondays 06:00. Closes out the prior week's CSAT, posts summary to ops channel.

Routing

in-app
Composer in any product cabinet (Mgmt + Dev + Owner) writes directly to support_tickets with the originating page URL attached.
email-to-ticket
support@{slug}.arconique.com aliases route through Postmark inbound. Thread continuity by Message-Id.
agent failure
If an agent run fails with customer impact (e.g. statement-preparer can't send), it auto-opens a P1 ticket and tags itself as the AI author.

AI rules

draft only
Default for all categories. Operator confirms every send. Edit distance to the final sent reply is logged for quality monitoring.
autosend
Allowed only for howto + bug · single org at >90% confidence. Toggleable per-category in policy.
never autosend
billing, P0 bugs, anything mentioning a refund/suspend/legal word. Even at 99% confidence.
