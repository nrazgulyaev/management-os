Feature flags · the rollout console.

One source of truth for every flag the app reads at request time. Five stages — off · internal · beta · GA · kill-switched — with per-org overrides for the inevitable "turn this on for one customer". The kill-switch row uses the same warm caution that impersonate and refund use: eyes go straight to it.

05—Spec

Schema · evaluation · consumers

Flag evaluation is read-mostly and hot. The evaluator caches per-org for 60s and per-user for 30s. Overrides bypass the cache key entirely. Writes (bumps, kills, overrides) bust the cache for the affected scope; the matrix view's "evaluated at" timestamp is the cache snapshot time.

Tables · new for 2.5

feature_flags
id · key · name · description · owner · stage · created_by · archived_at · ticket_url
flag_conditions
flag_id · idx · operand · op · value · conj — AND-joined in order, last row's conj ignored
flag_overrides
flag_id · scope (org/user) · scope_id · value (on/off) · reason · created_by · expires_at
flag_schedule
flag_id · planned_at · kind (bump/ga/kill/review) · payload_jsonb · created_by · executed_at
flag_audit
flag_id · actor_user_id · action · before · after · ip · ts — feeds cabinet 07

Evaluation order · top wins

1 · kill-switch
If stage = 'kill', return false. No exceptions.
2 · org override
Most-specific scope first. force-on → true, force-off → false, log hit.
3 · user override
For user-scoped flags only. Same precedence as org overrides.
4 · conditions
AND-joined; AB bucket uses hash(org_id + flag_key) % 100 for stable cohort assignment.
5 · default
If stage = 'ga', return true; else false.

Consumers · per-cabinet

middleware
src/lib/flags/evaluate.ts + useFlag() hook. Reads via x-product-aware context; the matrix UI calls the same evaluator with synthetic per-org user.
agents
Agent runners check command_palette_ai, id_ocr, voice_input before dispatching the corresponding agent. Disabled flag = no agent run, no spend.
UI rails
Owner-portal 2FA enrolment rail reads owner_portal_2fa_required. Statement explainers read statement_v2_explainers.

Caution-flow rules

kill-switch
2FA + reason. Logged to flag_audit + cabinet 07. Previous rollout state preserved; un-killing is a one-click restore.
GA flip
Cannot be scheduled for a weekend. Requires explicit confirmation if rolling to > 50% in a single step.
archive
Soft-delete. archived_at set; evaluator returns false. Row stays for audit-log integrity forever.
