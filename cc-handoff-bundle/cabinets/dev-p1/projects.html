Projects + project-manager cabinet

4-6 active villa-development projects at any time. Each project = a 12-30 month build (Eternal Phase 02 cluster, Ahau Phase 01 retrofit, etc.). Owned by a Project Manager who tracks budget burn, milestone schedule, RFI/RFA queue, and contractor performance. CFO and BOQ-QS cabinets read from Project records; this cabinet is where PM actually works.

Project Manager · CFO read • Engineering-grade UI
↓ IA ↓ List ↓ Project detail ↓ Milestones ↓ New project ↓ For Claude Code

Visual tone — engineering-grade

Dev OS uses Space Grotesk + IBM Plex Mono, amber accent on carbon-tinted surfaces. Less warmth than Mgmt, more precision. Numbers are everywhere — every column is tabular-nums, every variance gets a percentage, every milestone has a target date + actual date. Read like an engineer's spreadsheet, not a hotelier's dashboard.

Milestone editor

Milestone editor

Standalone tab + standalone route. Gantt-lite — flat list with dependency indicator. Click any milestone → side-sheet for editing dates, dependencies, owners. Don't build a real Gantt — it's not worth the complexity for <30 milestones per project.

Columns
Target date · name · owner staff · status · dependencies (chip list) · actual completion date · delta days
Status enum
planned → in-progress → blocked → done · plus at-risk derived state (target <14d but not started)
Dependencies
Many-to-many via milestone_dependencies table. Mark dependency as finish-to-start (default) or start-to-start. Drag to reorder visually.
Schedule variance
Per milestone: actual - target in days. Aggregated to project-level. Drives the project-level "schedule health" pill (Green ≤7d slip · Amber 7-21d · Red >21d).
Flow · New project

Onboard new project · 4-step lg flow

Step 1 · Identity
Project name · code prefix (EV-Phase-02 style) · type (new-build / retrofit / amenity) · target completion · brief description
Step 2 · Site
Location · land size · zoning · villa count · permits status
Step 3 · Phasing
Total budget · funding source · phases (design → permit → build → punchlist → handover) · target start/end per phase
Step 4 · Team + intake
Assign PM · core team roles · contractor pre-selection (optional) · enable AI agents (schedule variance / RFI router / weekly composer)
On submit
1. Creates project row
2. Seeds 4 baseline phase milestones
3. Provisions BOQ scaffold (empty workpackages)
4. Notifies PM with welcome packet
5. Schedules first weekly report for Friday
