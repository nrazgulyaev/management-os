Operations command center

The "what's happening right now" screen. GM opens this every morning and again throughout the day. Today's arrivals + departures, maintenance tickets queued by priority, housekeeping turnovers, staff assignments, SLA at risk. Pure operational triage — nothing here is "research", everything is "act now or in the next 4 hours".

GM · Ops Mgr · Housekeeping lead • opened 8–12×/day
↓ IA ↓ Today (hero) ↓ Maintenance queue ↓ Housekeeping board ↓ SLA model ↓ For Claude Code

Different from /dashboard

The Mgmt OS home (/dashboard) is the Director's morning brief — KPIs, anomalies, financial pulse. Operations is the GM's intra-day cockpit — task queues, today's arrivals, who's assigned what. Different audience, different cadence, different info density. They never overlap content; /dashboard hands off to Operations via "View today's ops →" tile.

SLA

Priority × SLA model

4 priorities · each with a target time to resolution. SLA status auto-computed every 5 min. Visible everywhere — list pills, hero tile counter, maintenance detail.

P0 · Crisis
Guest safety / displacement risk. Target: 2h. Auto-pages GM. Examples: gas leak, locked-out guest, flooding.
P1 · Urgent
Active guest impact. Target: 8h. Examples: AC failure during stay, hot-water out, broken security.
P2 · Standard
Pre-stay / between-stay. Target: 48h. Examples: pool pump intermittent, wifi router, ironing board missing.
P3 · Routine
Cosmetic / scheduled. Target: 14 days. Examples: light fixture cracked, lawn re-seed, linen rotation.
Status computation
For each ticket: age_h = now − created_at. Status:
· on-track if age_h < target × 0.6
· at-risk if age_h >= target × 0.6 && < target
· breached if age_h >= target
Breach side-effects
1. Visual: row tinted warn in list
2. Notification to GM + ticket owner
3. Logged to sla_breaches table
4. Counted in monthly SLA scorecard (Director's morning brief)
Why these targets
Calibrated to existing Bali contractor response times. Hard SLA <2h for P0 requires on-call GM + contractor on retainer. Soft for P3 (14d) lets us batch with routine maintenance visits.
