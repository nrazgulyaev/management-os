Mobile principles

Ops manager works the store rooms on foot. Phone has to make reorder one tap, but never auto-place — always confirms.

  1. 1-tap reorder on danger items → draft PO with vendor's preferred quantity.
  2. Review on warn items → opens 2-screen wizard (qty + vendor pick).
  3. No editing SKUs / vendors on phone — desk only.
  4. Stock count mode in More tab → barcode scanner + line-by-line.
  5. Director approval pending shows in Workspace attention feed, not here.

05—Implementation

Schema · agents · routes

Backed by existing inventory_* tables (mig 0006) + new inventory_par_levels + inventory_reorder_drafts. AI agent: inventory-forecaster for predicting run-outs.

sku · room_id · par_qty · reorder_threshold · vendor_preferred_id · lead_days · cost_unit
inventory_reorder_drafts
id · sku · vendor_id · suggested_qty · drafted_at · drafted_by_user_id · approved_at · approved_po_id (nullable)
inventory_stock_counts
id · room_id · counted_at · counted_by_user_id · line_count · reconciliation_jsonb

Agents

po-reconciler
on PO marked received · matches lines vs ordered · flags disputes via support ticket cabinet 06
