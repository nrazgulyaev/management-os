Mobile principles
  1. Inbox → tap row → thread takes screen.
  2. Agent messages styled distinctly from staff outgoing.
  3. "Templates" + "Quick rec" pinned to composer toolbar.
  4. Push notif on URGENT only (AC, ID, missing payment).
  5. Long-press a guest message → reply with template.
  6. Voice memo input via mic icon → auto-transcribes.

Routes
/dashboard/concierge · inbox + focused stay
/concierge/stay/[id] · single stay full page
/concierge/templates · message + comp templates
/concierge/recommendations · curated recos (restos, tours, activities) staff lookup
AI agents
concierge-agent · pattern-matches inbound requests · for routine asks (transfer, dinner, basic info) handles autonomously · for issues (AC, plumbing, safety) escalates immediately
comp-policy-checker · before any comp ≥ IDR 500k requires staff approval (modal)
journey-curator · scans stay daily · auto-adds journey moments from messages + activities · staff can edit/delete
recovery-monitor · when a request is tagged URGENT, monitors response time · escalates to manager if > 30min
Critical UX rules
1. Agent responses tagged visually as agent — never blend with staff messages. Guest sees clean replies (no "agent" tag); staff side always shows attribution.
2. Comps ≥ IDR 500k require explicit staff approval (modal). Below threshold, agent can offer autonomously and log it.
3. URGENT tag triggers manager push within 5min — recovery-monitor enforces.
4. Templates are versioned · changes log to audit; "live" template applies to new threads only.
5. Journey moments default to draft when agent-curated; staff promotes to "live" before they affect NPS pulse.
