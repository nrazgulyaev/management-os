⌘K command palette

Keyboard-driven everything. Navigate, run actions, jump to records, trigger agents — without the mouse. Same primitive across all 3 products; results vary by route context.

The 3 result types

Navigation — jump to a cabinet or screen. Actions — verbs (New booking, Approve statement, Run agent). Context-aware: actions visible to current screen come first. Records — fuzzy-search villas, bookings, owners, statements, projects. The big one — the search index is the same one that powers the topbar search input.

Spec

Sizing, keys, behavior

Trigger
⌘K (Mac) / Ctrl+K (Win/Linux). Also accessible by clicking the topbar search input.
Size
600px wide, max-height 480px. Position: centered horizontally, 100px from viewport top.
Keys (in palette)
↑↓ navigate, ↵ open, ⌘↵ open in new tab, Esc close. Hold ⇧ with ↑↓ to skip across groups.
Filter prefixes
> shows actions only, @ shows records only, / shows nav only. Typing a prefix at start narrows; otherwise all 3 types are searched.
Idle state
3 contextual actions (current page) + 5 recents + top-level jump cabinets. Recents = last 5 entities user opened (cached client-side).
Search latency
≤ 30ms for ≤ 10k records. Local fuzzy index via FlexSearch (already a small Mgmt OS dep) over name + code + meta fields. Server-side autocomplete for cold-cache cases.
Highlighting
Matched substrings wrapped in <mark> with accent-tinted bg. Preserves case of source text.
Empty results
"No matches for 'xyz'. Try removing characters or use > for actions." Compact, single-line, no big empty-state primitive.
Theming
Inherits product palette. Selected item border-left = var(--accent), selected icon bg = accent solid. Same chrome across Mgmt/Dev/Owner.
For Claude Code

Where this lands

New file
src/components/command-palette.tsx — client component (keyboard handler + state). Wrap in src/components/command-palette-provider.tsx that mounts the global ⌘K hotkey listener and Radix Dialog wrapper.
Mount
Once in src/app/layout.tsx at root. Renders nothing visually; opens on ⌘K.
Source registry
New src/features/command-palette/sources.ts exports getCommandSources(ctx) → returns { records, actions, navigation }. ctx = current pathname + product + selection state.
Actions per page
Each cabinet exports commandActions from a co-located file (e.g. dashboard/bookings/_command-actions.ts). Pattern: export const commandActions: CommandAction[] = [{ id: "new-booking", label: "New booking", kbd: "⌘N", run: (router) => router.push("/dashboard/bookings/new") }]
Search index
FlexSearch on client. Hydrated on first open from /api/command-palette/index which returns serialized records (names, codes, meta) for tenant-visible entities. Capped at 10k newest.
CSS
New section in src/styles/components.css. [data-product] .ck, .ck-input, .ck-item, etc.
Recents
localStorage key arconique.recents.{userId} · max 20 entries · pushed on every detail-page open via the Activity primitive's existing emit hook.
Telemetry
Emit command_palette_opened + command_palette_action_chosen with action ID + query length + position in results. Helps tune what shows in idle state.
