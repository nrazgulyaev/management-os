List + filter

The single-most-used screen shape: a table of records with filtering and bulk operations. Medium-complexity spec — covers 90% of cabinets (Bookings, Owners, Statements, Maintenance, Procurement, Investors). Query builder + saved views are NOT in this template — they live as extensions on specific high-volume cabinets in 2.2.

Medium • 4 anatomy zones

Anatomy

1. Page header (uses primitive from design system §10). 2. Filter bar — search input + active-filter chips + "+ Filter" trigger + view selector. 3. Optional faceted side panel (collapsed by default; expand for refining list at scale). 4. Table — sortable columns, row selection, bulk action bar slides in on top. 5. Pagination at bottom (uses primitive 03).

Spec

Anatomy & behavior

Filter chip
Pill with mono-uppercase label + value + ×. Active = solid ink bg, inactive = paper. Click chip to edit (opens dropdown). Click × to remove.
"+ Filter" trigger
Dashed border, mono-uppercase label. Opens a popover listing available facets to add. After selection, becomes a chip.
View selector
Right-aligned. Shows current saved view name (e.g. "This month", "My active bookings"). Click to switch view OR open "Manage views" (in 2.1 scope: just switch; saved views CRUD ships in 2.2 if needed).
Search input
Debounced 300ms. Searches across visible columns by default. Power users can use villa:enso prefix syntax — auto-extracted into chip on Enter.
Faceted side panel
240px wide. Closed by default. Toggle via filter bar overflow menu. Counts update live as other filters change. Multi-select within group (OR), between groups (AND).
Sort
Click sortable column header → toggle asc/desc/none. Shift-click for multi-column sort. Sorted columns show arrow in accent color; unsorted show neutral ↕.
Row selection
Header checkbox = "select all on this page" (NOT across pages — show confirmation if user wants all 248). Selected rows: tinted bg color-mix(in oklab, var(--accent) 5%, transparent).
Bulk action bar
Replaces filter bar when ≥1 row selected. Solid ink bg, white text. Actions are contextual to the table (Bookings has Cancel; Owners has Email). Always end with "Clear selection".
URL state
Filters + sort + page sync to query string (?status=confirmed&channel=airbnb,direct&sort=code:desc&page=3). Saved view = preset of these params.
Empty state
If filters → 0 rows, use empty-state primitive variant no-results with "Clear all filters" CTA. If table is empty regardless of filters, use first-run.
