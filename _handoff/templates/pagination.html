Pagination

Three variants by data shape: numbered pages for finite paginated lists, "load more" for append-on-scroll feeds, cursor-only for very large or stream-y tables.

3 variants • used on every list

Pick by data shape

Numbered — finite, bounded sets where the user benefits from knowing total + jumping (Bookings list, Owners list, Statements). Load more — feeds where chronological browse is the pattern (Concierge transcript, Activity log, AI agent runs). Cursor — very large tables (BOQ lines: 142 rows, Procurement RFQs) where counting is expensive or stream is more important than jumping.

Spec

Sizing & behavior

Bar height
~60px (14px padding + 32px button row + extra for wrap on mobile)
Page button
Min 32 × 32px hit target. On state = solid var(--ink), hover = lift to paper bg with border.
Truncation
Always show: first page, current ± 1, last page. Truncate the middle with …. So pager never has more than ~8 visible buttons even for 50-page sets.
Per-page picker
20 / 50 / 100. Default 20. Persist user choice in localStorage per route key.
Jump input (cursor)
Accepts page code or row identifier (depends on table — BOQ accepts WP-04.21, bookings accept BK-2148).
Mobile
Bar wraps. Numbered pager shows only ‹ / current of total / ›. Per-page picker collapses into a sheet trigger.
URL state
Page + per-page sync to query string (?page=3&per=50) so deep links work and back/forward navigate correctly.
Empty
When total = 0, hide the pager entirely — let the empty-state primitive (02) own the surface.
For Claude Code

Where this lands

New files
src/components/dashboard/pager-numbered.tsx · pager-loadmore.tsx · pager-cursor.tsx — three separate primitives, not one polymorphic component. They share zero internal logic and have different prop shapes.
Props (numbered)
total: number · page: number · perPage: number · perPageOptions?: number[] · onChange(page, perPage)
Props (loadmore)
shown: number · total: number · step?: number · onLoadMore() · loading?: boolean
Props (cursor)
rangeLabel: string · cursor: string · onPrev() · onNext() · onJump?(code: string) · hasPrev: boolean · hasNext: boolean
URL sync
Numbered + cursor variants accept optional urlKeyPrefix prop that writes/reads ?{prefix}page, ?{prefix}per, ?{prefix}cursor via useSearchParams + useRouter.
CSS
New rules in src/styles/components.css after the existing table.data block. Add [data-product] .pager + .loadmore + .cursor modifiers.
localStorage key
arconique.pager.perPage.{routeKey}. routeKey = first 2 path segments (e.g. dashboard.bookings, development-os.qs). Falls back to global default 20.
