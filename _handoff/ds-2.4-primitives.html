Design system · extension · 2.4

Five new primitives for Mgmt P2 + Dev P2.

Phase 2.4 introduces seven cabinets — four in Management OS, three in Development OS. Five of those cabinets need primitives the base design system doesn't yet have. This document is the pixel-spec for those five. After review they ship as src/styles/components-2.4.css + component files under src/components/{channels,pricing,site-reports,sales,investors}/.

02—Dynamic pricing

PricingCurve

Forward-90-day rate curve per villa. Draggable handles override the algorithm at specific dates. Overlays: comp set, ADR forecast, last-year actual. Annotated with events (school holidays, conferences).

Mgmt P2

Anatomy — 90-day pricing curve, one villa

villa tirta · 90-day forward
Rate curve — IDR · base + algo + overrides
algo recommendation active rate (overrides applied) last year actual comp set median
jul 15 · IDR 720 +38% algo
override · G20 demand spike
period 90d period 30d period 365d overlays algo + active + comp + ly events on 3 overrides active · drag handles to edit
Y-axis
IDR, 4 grid lines, snaps to nearest 50
X-axis
days (3-month spans default to weekly labels)
Algo line
--ink-2, 2px, solid — what the engine wants
Active line
--terra (Mgmt) / --amber (Dev), 2.5px, solid — what's actually pushed
Overlays
last-year actual (--ink-4, dashed) · comp-set median ± band (--sage, dashed with fill 6% opacity)
Handles
r=5 default, r=6.5 active. Hover/drag → tooltip with date + value + delta vs algo
Events
vertical guides — dashed --line-strong for neutral, --gold for high-demand events
Today
solid 1.5px --terra line, no fade
Tech
Recharts <LineChart> with custom dot + reference lines · drag = controlled via mouse events on dot
