  - `per_invocation_cap_cents` → `per_invocation_budget_minor`

New agents seed with the standard `'anthropic'` provider; "Coming soon · Configure key" renders until the operator wires an API key through the existing per-agent BYO UI at `/dashboard/settings/ai-agents/[agent_key]`.
- Aggregator-source tables confirmed:
  - Subcontractors → `work_packages.primaryVendorId` (no clean subcontractor pivot)
  - Project completion → `work_packages.progressPercentage` + `actualFinish`
  - Lead attribution → `leads.firstTouchSourceKey` → `marketing_lead_sources.sourceKey`
  - Channel split → `content_variants.platformTarget` (no explicit channel on content_pieces)
  - Forecast cashflow → `dev_budget_lines.effectiveFrom` + `capital_drawdowns.requestedDrawdownDate` (projected outflows + inflows)
