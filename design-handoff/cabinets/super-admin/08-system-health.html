04—Spec

Schema · alerts · sources

Health is read-only — it's a view onto data the rest of the platform already writes. The alert routing layer is the one new thing: a small table of alert rules that watches the queue/sync/api metrics and pages the right channel. Pagerduty for P0; slack channel for P1+; nothing for P2 (just the strip).

Data sources · existing

job_runs
pg-boss queue history table · already exists. Adds run_id · runner · args_jsonb · output_jsonb · attempt · status · started_at · finished_at.
channel_sync_log
Per-cell sync attempts · already in main from Phase 2.4 channel cabinet.
http_request_log
Vercel + edge logs streamed to Postgres in 5m batches. API p95 / error rate read from this.
stripe_webhook_log
Every Stripe webhook ack timestamp. Lag = now - last_ack.
audit_log
Cabinet 07. Tech lead can pivot from a queue failure to the audit row.

Tables · new for 2.5

alert_rules
id · metric (e.g. queue.depth · sync.err_rate · webhook.lag) · op · threshold · window · severity · route (pagerduty / slack / strip)
alerts
rule_id · fired_at · ack_at · ack_by · resolved_at · payload_jsonb · related_runs[]
incidents
opened_at · closed_at · summary · severity · linked_alerts[] · postmortem_url — optional, for breach > 15m

Alert routing

P0 · pagerduty
API 5xx rate > 1% · DB connection saturation · sync error rate > 10% any channel
P1 · slack #ops
Webhook lag > 30s · queue depth > 5000 sustained 5m · single-channel err > 5% · 3+ dead-letters in 1 hour
P2 · strip only
Webhook lag 10-30s · sync err 1-5% single channel · postmark bounce rate > 1%
auto-ticket
Every dead-letter run opens a ticket in cabinet 06 (P1) tagged with run-id + org. Resolves when run replays clean.

Dashboards · who watches what

tech lead
This page · pinned in browser. Pagerduty on phone for P0. Slack #ops for P1.
sales / ops
Only sees the strip (P1+ active) on this page. Cabinet 06 surfaces auto-opened tickets.
customers
Public status page at status.arconique.com reads the same alert table · subset (no internals).
retention
Job runs · 90d hot · 2y cold. Channel-sync log · 30d. Alerts · 1y. Incidents · forever.
