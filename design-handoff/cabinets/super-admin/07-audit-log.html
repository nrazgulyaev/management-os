04—Spec

Schema · retention · sources

One table, partitioned by month, append-only at the database role level (super-admin DB user has no UPDATE or DELETE grants on it). Writers from every cabinet funnel through a single writeAudit() helper. Retention is forever — the legal cost of explaining a deleted audit row is higher than the storage cost.

Table · `audit_log`

id
au_* · ULID · sortable by time
ts
UTC timestamp · partition key (monthly)
actor
actor_type (user/agent/system) · actor_id · actor_label
scope
org_id (nullable for platform-wide) · resource_type · resource_id
action
verb (refund.issue, flag.kill, impersonate.start, …) · class (money/auth/config/write/read/danger)
diff
before_jsonb · after_jsonb · field_count — null for read actions
justification
free-text · plain language · null for routine actions
source
cabinet · route · ip · ua · session_id
linked
external_ids_jsonb — stripe ids, agent run ids, related audit ids

Append-only enforcement

db role
The platform DB role has INSERT + SELECT on audit_log. No UPDATE · no DELETE. Enforced at pg_authid.
writer
Single helper src/lib/audit/write.ts · every cabinet imports this. Direct SQL INSERT blocked by a CI grep.
partitioning
Monthly partitions · audit_log_2025_05 etc. Old partitions detach to cold storage after 24 months but remain queryable on demand.

Writers · who calls `writeAudit()`

cabinet 01–09
Every super-admin action (impersonate, suspend, plan change, refund, flag bump, policy edit).
mgmt-os · dev-os
Customer-side privileged actions (villa.create, owner.invite, statement.adjust, role.change).
owner portal
Owner sign-in, payout update, 2FA enrolment, statement export.
agents
All cron + trigger runs that mutate data write a row. Read-only agent runs are NOT logged (would 10× the table).

Query patterns

live feed
Last 24h · indexed on ts DESC · streamed via Postgres LISTEN/NOTIFY · 1–2s lag.
org forensics
By org_id + time range · indexed on (org_id, ts DESC). Common query: "all money actions on org X in last 30d".
actor forensics
By actor_id + time range · indexed. Used during ops investigations: "everything Nikita touched yesterday".
customer-facing audit
Owners can see their own org's actions in the owner-portal Settings page (read-only, filtered subset).
